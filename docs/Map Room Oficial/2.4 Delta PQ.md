## 🌀 2.4 ΔPQ – Diferença de Qualidade Posicional

O **ΔPQ** é a diferença entre a **qualidade do terreno/construção do atacante e do defensor**. Ele não afeta FD diretamente, mas **altera a curvatura da realidade tática**, influenciando o arredondamento.
``ΔPQ = PQ_atacante - PQ_defensor`  
*(Valores de PQ baseados no terreno/construção:)*

⚠️ _Importante:_ O **ΔPQ** altera o arredondamento de **ambos os lados**, mas **a partir da perspectiva do atacante**. Isso cria situações onde a desvantagem posicional pode se tornar um fator decisivo na defesa.

| Degrau | Nível PQ  | Exemplos               |
|--------|-----------|------------------------|
| 0      | Desfavorável | Praia, pântano, estrada |
| 1      | Padrão    | Mar, planície         |
| 2      | Melhorado | Floresta, cidade      |
| 3      | Favorável | Montanha, forte       |
### Regras de Arredondamento:
| ΔPQ  | Comportamento                  | Exemplo (4.0) | Exemplo (5.71) |
| ---- | ------------------------------ | ------------- | -------------- |
| ≤ -2 | ↓ Atacante / ↑ Defensor        | **3** (-1)    | **5** (↓)      |
| = -1 | Arredondamento padrão (0.5+ ↑) | 4             | **6** (↑)      |
| ≥ 0  | ↑ Atacante / padrão Defensor   | **5** (+1)    | **6** (↑)      |
| ≥ 2  | ↑ Atacante / ↓ Defensor        | **5** (+1)    | 6 (↑)          |

> **Efeito em Resultados Inteiros:**  
> - "↑" adiciona +1  
> - "↓" subtrai -1 (mínimo 0)  

> **Caso Destroyers (ΔPQ = -2):**  
> `4.0 → 3 eliminados` *(aplicado ↓: 4 - 1 = 3)*

### Diagrama Conceitual do ΔPQ:
ΔPQ = Atacante - Defensor  

| Qualidade        | Situação | Posição                 |
| ---------------- | -------- | ----------------------- |
| Favorável (3)    | ▲        | (Defensor:  Obus Pesado |
| Melhorado (2)    | │        |                         |
| Padrão  (1)      | │        |                         |
| Desfavorável (0) | ▼        | (Atacante: Destroyer)   |
