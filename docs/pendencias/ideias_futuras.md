# Registro de Ideias Futuras
**Origem:** The Map Room Design Docs

Este documento mantém o escopo de features conceituais projetadas para expansões ou *tool-gates* de fim de projeto, servindo como uma base primária para os designers.

- **Times Aliados (2v2):** O jogo no código atual roda num modelo puramente "todos-contra-todos". Adicionar suporte a um sistema formal de alianças entre facções é uma ideia futura que ainda será avaliada.
- **Multiplayer em Rede:** O pilar para competição entre as facções prevê formalmente três modalidades. Hoje o código acomoda o *Hotseat local*; os outros dois patamares (*Multiplayer Assíncrono* e *Multiplayer Síncrono*) repousam como features de "tool-gate" aguardando a consolidação final do projeto.
- **Condições de Vitória Configuráveis:** Planejamento para uma expansão da tela de setup, onde o jogador escolherá ativamente as alavancas de vitória da partida para além das diretrizes padrões (controle numérico de Estrelas, queda de Quartel-General, Limite global de Turnos ou Metas de Suprimentos).
